## 🎖️ GitHub Achievements Triggered & Unlocked

| Badge | Nama Achievement | Keterangan & Trigger | Status |
| :---: | :--- | :--- | :---: |
| ⚡ | **Quickdraw** | Menutup Issue/PR dalam kurun waktu kurang dari 5 menit setelah dibuat | ✅ **Unlocked** |
| 🤠 | **YOLO** | Melakukan merge Pull Request tanpa code review / blocking check | ✅ **Unlocked** |
| 👥 | **Pair Extraordinaire** | Melakukan commit bersama (*Co-authored-by*) yang di-merge ke branch utama | ✅ **Unlocked** |
| 🦈 | **Pull Shark (Silver)** | Membuka dan melakukan merge hingga 16+ Pull Requests | ✅ **Unlocked (Silver)** |
